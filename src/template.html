Scene script


  

    What a script can do
    

      
await frame(shapes, fx)
Draws one frame, waits for the next, and returns { t, dt, frame, w, h, cx, cy, mx, my, down, audio }. It is the only door out of the VM.

      
s.audio
bass, mid, high, level and slow energy (0–1); kick jumps to 1 on a beat and decays; beat is true on beat frames; beats counts them; bands is 32 values from lows to highs.

      
Sound types
kickHit, snareHit, hatHit are true on the frame each kind of drum hits; kick, snare, hat are 0–1 envelopes (slow, medium, fast decay); kicks, snares, hats count them. snap/snapHit follow the snare.

      
Timbre
bright 0–1 (spectral centroid: dark to bright), noise 0–1 (spectral flatness: tonal to noisy) and tonal; chroma is 12 pitch-class strengths, note the loudest now, key the tonal centre and keyHue its colour on the circle of fifths.

      
Rhythm
beat comes from a phase-locked beat clock, steady even when a kick is missed; phase 0–1 between beats, anticip ramps up in the last quarter-beat before the next one, bar 0–3, barPhase 0–1 across the bar, downbeat on each "1", phrase 0–7 bar in the 8-bar phrase, phraseStart, bpm, beatConf.

      
Sections
calm 0–1 in breakdowns and quiet intros; drop true on the frame a drop lands, dropAmt 1 then fading over about 2 s. A drop also makes the director cut.

      
Song map
For mapped songs: section ("intro", "verse", "build", "drop", "main", "breakdown", "outro"), build 0–1 rising through a build, toDrop seconds to the next drop, sectionPos and songPos 0–1. Hits and beats come from the map, so they stay exact when you seek.

      
{ k: "c", x, y, r }
Circle, filled unless fill: false.

      
{ k: "p", pts }
Path through [x0, y0, x1, y1, …]. Closed unless close: false; outlined unless fill: true.

      
{ k: "l", x1, y1, x2, y2 }
Line.

      
{ k: "t", text, x, y, size }
Text.

      
Colour
h hue in degrees, s and l in %, a 0–1, lw line width.

      
fx.trail
How much of the last frame survives, 0–0.995.

      
fx.zoom, fx.spin
Feedback scale per frame (1 is still) and rotation in radians.

      
fx.hue
Degrees the old frames drift in colour each frame.

      
fx.mirror
Kaleidoscope slices (even number, 0 for off).

      
fx.react
Optional { punch, slice, sparkle, shake, tint } 0–2: how strongly the frame itself reacts to kicks (zoom punch), snares (slice glitch), hats (shimmer), bass (shake) and the key (colour grade).

      
fx.blend
"lighter" (glow), "screen", "difference" or "source-over".

      
Not here
No timers, DOM, fetch or eval. A loop that never awaits frame() is stopped after 3 s. Auto-cycle pauses while you edit.

    

  






  
Trance Engine

  
A music video directed live by the music. Feature scenes tell the story in phases, flourishes punctuate it, and every scene is a small program running inside a sealed Psychoscript VM that hears the song only through frame().

  

    
    
    
    
    
    
    
  

  Every song is mapped first (beats, sections, builds, drops), so cuts land on the music, and scrubbing the timeline rewinds the scenes themselves from VM snapshots. You can also drop an audio file anywhere; it plays and is mapped on your device and is not uploaded.
